# دعوة خطوبة روان و حسين

الرابط: https://efe4z.github.io/rawan-hussein-invite/

موقع دعوة: ظرف كحلي بزخارف دمشقية ذهبية، بتكبس على الختم، الزخارف بتضوي، الغطا بينفتح، والكرت بيطلع وبيصير صفحة الدعوة.

---

## ١. شو في بالمجلد

| الملف / المجلد | شو هو |
|---|---|
| `config.js` | **كل النصوص والتاريخ والمكان والأغنية. هاد الملف الوحيد اللي غالباً رح تعدّل فيه.** |
| `index.html` | هيكل الصفحة |
| `css/style.css` | الألوان والتنسيق |
| `js/app.js` | الحركة والصوت والعدّاد والفورم |
| `js/ornaments.js` | رسم الزخارف الدمشقية |
| `assets/` | صور الورق والمخمل والختم |
| `fonts/` | الخطوط (Gulzar، Markazi Text، Amiri) محفوظة جوّا الموقع |
| `audio/` | ملف الأغنية `song.mp3` |
| `og-image.jpg` | الصورة اللي بتطلع لما تبعت الرابط على واتساب |
| `vendor/gsap.min.js` | مكتبة الحركة |
| `google-sheet-script.gs` | كود جدول Google لتأكيدات الحضور (بينسخ لـ Apps Script) |
| `.nojekyll` و `.gitignore` | ملفات صغيرة لـ GitHub Pages، لا تمحيهم |
| `_generated/` | الصور الأصلية بدقة عالية (للتعديل لاحقاً، مش ضرورية للنشر) |

## ٢. تجربة الموقع على جهازك (VS Code)

1. افتح المجلد بـ VS Code: `File → Open Folder` واختار `rawan-hussein-invite`.
2. نزّل إضافة **Live Server** (من قسم Extensions، ابحث عن Live Server لـ Ritwick Dey).
3. كبسة يمين على `index.html` ← **Open with Live Server**.
4. كل ما تحفظ تعديل، الصفحة بتتحدّث لحالها.

> لتجرّب شكل الجوال: بالمتصفح اكبس `F12` ← أيقونة الجوال (Toggle device toolbar).
> لتشوف صفحة الدعوة مباشرة بدون الظرف: زيد `#invite` آخر الرابط، مثلاً `http://127.0.0.1:5500/#invite`

## ٣. تعديل النصوص (`config.js`)

عدّل بس اللي بين علامات التنصيص `"..."` واحفظ.

- **التاريخ:** بـ `date.full` (حالياً `"13.11.2026"`)، واسم اليوم بـ `date.dayName`، والهجري بـ `date.hijri`.
- **الوقت:** النص بـ `time.from` و `time.to` (حالياً «من 2 ظهراً» و«حتى 6 مساءً»). وإذا تغيّر الموعد، عدّل كمان `hour` و `durationHours` بـ `event` (نظام ٢٤ ساعة بتوقيت سوريا: 14 = الساعة 2 الظهر) مشان العدّاد والتقويم يضلوا مضبوطين.
- **رابط جدول التأكيدات:** بـ `rsvp.sheetUrl` (شوف القسم ٦).
- **الفتح التلقائي:** `autoOpenSeconds` (حالياً 6 ثواني). خلّيه `0` إذا بدك الظرف ما ينفتح غير بكبسة.
- **رقم الواتساب (لسا ناقص):** بـ `rsvp.whatsapp` اكتب الرقم مع رمز الدولة وبدون + أو أصفار بالأول، مثلاً `"963944123456"`. لما يكون فاضي، زر «أو أكّد على الواتساب» ما بيبين.
- **أي نص بدك تخفيه:** خلّيه فاضي `""` وما بيطلع.

## ٤. الأغنية

- الأغنية الحالية: «حلم حياتي» من الدقيقة 2:14 لآخرها (تقريباً دقيقة)، محفوظة بـ `audio/song.mp3`.
- بتبلّش لما الضيف يكبس على الختم، وإذا الظرف انفتح لحاله بتبلّش مع أول لمسة للشاشة (الجوالات بتمنع الصوت قبل أول لمسة). بتطلع بهدوء خلال ثانيتين، ولما تخلص بتنطفي بهدوء وبتعيد.
- لتغيّرها: حط ملف mp3 جديد بمجلد `audio` واكتب اسمه بـ `music.file` بـ `config.js`. خلّي حجمه صغير (تحت ٢ ميغا تقريباً) مشان يحمّل بسرعة على الجوال.
- لتشيل الموسيقى: خلّي `file: ""`.

## ٥. النشر على GitHub Pages (من VS Code)

**أول مرة:**
1. اعمل حساب مجاني على [github.com](https://github.com) إذا ما عندك.
2. افتح المجلد بـ VS Code، وروح على أيقونة **Source Control** بالشريط الجانبي (أو `Cmd+Shift+G`).
   - إذا طلب منك تنزيل Git، وافق وكمّل التنزيل وارجع.
3. اكبس **Publish to GitHub** واختار **Publish to GitHub public repository** (لازم يكون Public ليشتغل GitHub Pages مجاناً).
   - سمّي المستودع `rawan-hussein`، ولما يسألك عن الملفات خلّيهم كلهم.
   - رح يفتحلك المتصفح لتسجّل دخول على GitHub وتسمح لـ VS Code.
4. بعد ما يخلص، افتح المستودع على github.com ← **Settings** ← **Pages**.
5. تحت **Build and deployment**: الـ Source خلّيه **Deploy from a branch**، والـ Branch اختار **main** و **/(root)**، واكبس **Save**.
6. استنى دقيقة أو اتنين، وبيطلعلك فوق الرابط: `https://اسم-حسابك.github.io/rawan-hussein/`

**بعد أول نشر، ضروري:**
- **صورة الواتساب:** مضبوطة على الرابط الكامل `https://efe4z.github.io/rawan-hussein-invite/og-image.jpg` بـ `index.html`. إذا تغيّر اسم المستودع أو الحساب لازم تغيّرها كمان. (واتساب ما بيقبل غير رابط كامل.)

**لما تعدّل أي شي بعدين:**
1. احفظ بـ VS Code.
2. بـ Source Control اكتب كلمة بخانة الرسالة (مثلاً «تعديل الوقت») واكبس **Commit**، وبعدها **Sync Changes**.
3. بعد دقيقة بيتحدّث الموقع لحاله.

## ٦. جدول تأكيد الحضور (Google Sheet)

كل ضيف بيعبّي الفورم، والرد بينزل لحاله بجدول Google. الجدول فيه صفحة **الملخص**: مجموع الحاضرين، وعدد المعتذرين، وأسماء الكل. وإذا Google ما زبط عند ضيف (مثلاً حجب بسوريا)، الموقع بيعطيه زر واتساب والرسالة جاهزة لرقمكن.

**الإعداد (مرة وحدة، حوالي ١٠ دقايق):**
1. افتح [sheets.new](https://sheets.new) (جدول جديد) وسمّيه «تأكيد حضور خطوبة روان وحسين».
2. من القائمة: **Extensions ← Apps Script**.
3. امحي الكود الموجود، وانسخ محل كل محتوى ملف `google-sheet-script.gs` واحفظ (`Cmd+S`).
4. من فوق اختار الدالة **setup** واكبس **Run**.
   - رح يطلب صلاحيات: **Review permissions** ← اختار حسابك ← **Advanced** ← **Go to … (unsafe)** ← **Allow**. (التحذير طبيعي لأن الكود إلك ومش منشور.)
5. **Deploy ← New deployment** ← من الدولاب اختار **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
   - اكبس **Deploy** وانسخ رابط الـ **Web app** (بيخلص بـ `/exec`).
6. حط الرابط بـ `config.js` بـ `rsvp.sheetUrl` واحفظ وارفع التعديل (Commit ← Sync).

**التجربة:** افتح الموقع من جوالك، عبّي تأكيد باسم «تجربة»، وشوف إذا نزل بالجدول. بعدها امحي السطر.

> إذا عدّلت الكود بـ Apps Script لاحقاً، لازم تعمل **Deploy ← Manage deployments ← Edit ← New version** ليشتغل التعديل.

## ٧. روابط شخصية لكل ضيف

زيد `?to=` واسم الضيف آخر الرابط:

```
https://efe4z.github.io/rawan-hussein-invite/?to=عائلة أبو أحمد
```

بيصير مكتوب على الظرف «إلى عائلة أبو أحمد» بدل «إلى ضيوفنا الأعزّاء». (الاسم بيطلع عالظرف بس.)
